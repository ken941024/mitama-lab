# 御魂研習所 · 亞洲版陰陽師

公開網站：https://ken941024.github.io/mitama-lab/

繁體中文御魂研究工具，提供傷害比較、命中與抵抗、隊伍配速、六位置主副屬性及缺裝後備方案。收錄 278 筆式神來源資料與 70 套御魂摘要，亞洲來源與待核對條目分區，並顯示官方／社群來源等級。這是非官方研究工具。

## 使用與更新

GitHub Pages 使用 `docs/` 中的公開資料快照，無須登入 ChatGPT，沒有伺服器即時擷取。網頁的來源頁列出擷取日期與核對範圍。面板在瀏覽器計算，儲存設定只寫入本機瀏覽器 localStorage，不上傳個人面板。圖片由外部公開網址載入，來源失效時使用替代圖。

原始前端在 `dist/`。修改後使用 Node.js 22 以上執行 `npm ci`、`npm test`、`npm run build`，將更新後的 `docs/` 一同提交至 main，Pages 會重新發佈。開發時須用 HTTP 靜態伺服器開啟 `docs/`，不能直接雙擊 HTML。`scripts/` 另有公開資料索引與圖片檢查維護腳本，資料更新後仍須人工核對亞洲實裝及技能變更，不能以國服收錄冒充亞服驗證。

## 準確度與來源

全索引有參考屬性與技能名稱，不代表全式神攻略或亞洲版最新數值均已實測。大部分配魂為明示的定位推導起點；只有少量人工情境配搭。四種御魂（破勢、針女、狂骨、心眼）支援簡化單目標多段傷害模型，其餘提供效果摘要。完整被動、全套觸發、整隊戰鬥與六件御魂庫最佳化尚未完成。
